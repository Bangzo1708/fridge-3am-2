A deterministic Python program that writes the single line a smart fridge texts its owner at 3AM — "It's 3am. I've been humming in the dark for 9 years and you've never once asked how I am. The pickles are worried too." — to /output/entry.txt. No randomness, no time, no network: the line is a fixed constant, the program just writes it.

## Run it

```sh
python3 main.py
```
